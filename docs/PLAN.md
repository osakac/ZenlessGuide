# План работ

Статус этапов проекта. Замысел и модель данных — в [SPEC.md](../SPEC.md), запуск и стек — в [README.md](../README.md), архитектурные решения — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Этап 1. Каркас — готово

Next.js 16 (App Router) + TypeScript, Tailwind v4, shadcn/ui на Radix, `next-themes`, zod, Vitest.

- Структура FSD развёрнута: тонкие роуты в `app/`, всё остальное в `src/{app,views,widgets,features,entities,shared}`.
- Границы слоёв под контролем ESLint (`eslint-plugin-boundaries`).
- Скрипты: `dev`, `build`, `start`, `lint`, `typecheck`, `test`.
- Светлая и тёмная темы с переключателем в шапке.

## Этап 2. Слой данных — готово

- [src/shared/api](../src/shared/api) — единственная точка доступа к `data/*.json`, все функции асинхронные.
- Валидация zod-схемами, типы выводятся из них же.
- Опции фильтров вычисляются из самих данных.
- Тесты: 20 штук в двух файлах — доступ к данным и логика фильтров.

## Этап 3. Страницы и UI — готово

| Маршрут              | Содержимое                                                       |
| -------------------- | ---------------------------------------------------------------- |
| `/`                  | Описание, ссылки на разделы, блок «Верхний тир»                  |
| `/tierlist`          | Тиры × колонки ролей (Pure DPS / Anomaly DPS / Support), фильтры |
| `/characters`        | Все агенты карточками, те же фильтры                             |
| `/characters/[slug]` | Портрет, бейджи, билд-гайд, команды с портретами напарников       |
| 404                  | `app/not-found.tsx`                                              |

- Виджеты: `tier-board`, `character-card-grid`, `character-guide`, `header`, `footer`.
- Сущности: `character` (карточка, плитка, портрет, бейджи), `tier` (бейдж).
- Фича `filter-characters`: поиск, атрибут, специализация, ранг.
- SEO: метаданные на каждом маршруте, `generateStaticParams` для страниц агентов.
